# Ankara SuNokta — web

[Ankara SuNokta](https://ezirah.github.io/sumatik-app-web/) uygulamasının
destek ve gizlilik sayfaları. GitHub Pages ile `main` dalından yayınlanır.

| Sayfa | URL | App Store Connect alanı |
|---|---|---|
| Destek | `https://ezirah.github.io/sumatik-app-web/` | Support URL |
| Gizlilik Politikası | `https://ezirah.github.io/sumatik-app-web/gizlilik/` | Privacy Policy URL |

Kaynak metinler uygulama deposundaki `docs/` klasöründe tutulur
(`gizlilik-politikasi.html`, `kvkk-aydinlatma-metni.md`); burası yayın kopyasıdır.
Politika değişirse **her iki yerde de** güncellenmeli ve "son güncelleme"
tarihi ilerletilmelidir.

## Yerelde bakmak

```bash
python3 -m http.server 8080
```
